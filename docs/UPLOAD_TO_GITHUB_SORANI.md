# ناردنی پلاتفۆرمی بیر بۆ GitHub

ئەم پڕۆژەیە بەتاڵە؛ کارتەکانی خۆت لەناو ئەپەکەدا هاوردە دەکەیت. بۆ ناردنی کۆدی پلاتفۆرمەکە بە GitHub Desktop:

1. ئەگەر ZIPت وەرگرتووە، بە **Extract All** بیکەرەوە. فۆڵدەری پڕۆژەکە دەبێت `index.html`، `README.md`، `package.json` و `media/.gitkeep`ی تێدا بێت.
2. GitHub Desktop بکەرەوە و بە **File → Add local repository → Choose** هەمان فۆڵدەری پڕۆژەکە هەڵبژێرە.
3. ئەگەر فۆڵدەرەکە repository نییە، **create a repository here** هەڵبژێرە. ڕێڕەوی کۆتایی دەبێت هەمان فۆڵدەری پڕۆژەکە بێت. README و `.gitignore`ی ئامادە هەیە؛ READMEی نوێ پێویست نییە.
4. لە **Changes** فایلەکان بپشکنە، لە **Summary** بنووسە `Add empty Bir flashcard platform` و **Commit to main** بکە؛ ناوی لقەکە لەوانەیە جیاواز بێت.
5. **Publish repository** هەڵبژێرە و ناو، ئەکاونت و دیاربوونی پڕۆژەکە دیاری بکە. پاشان **Publish repository** بکە.
6. بە **Repository → View on GitHub** فایلە بڵاوکراوەکان ببینە. فایلەکانی پڕۆژەکە بنێرە، چونکە ناردنی تەنها ZIP ناوەڕۆکەکەی لە GitHub ناکاتەوە.

`media/.gitkeep` بەجێ بهێڵە تا فۆڵدەری `media/`، کە بۆ وێنە هاوردەکراوەکان بەکاردێت، لە کۆپییەکانی پڕۆژەدا بمێنێتەوە. پاشەکەوتی وێبگەڕ خۆکارانە ناچێتە ناو repository؛ کارتەکان و پێشکەوتن لە ڕێکخستنەکانی ئەپەکە بە JSON هەناردە دەکرێن.

بۆ بەکارهێنانی ناوخۆیی، `index.html` بکەرەوە. بۆ APKG، سێرڤەری ناوخۆیی پێ بکە:

```sh
python server.py --port 64008
```

پاشان `http://127.0.0.1:64008/` بکەرەوە. پێداویستییەکانی Python، PowerShell 7 و Anki لە [README](../README.md) باس کراون. میواندارییەکی ستاتیکی وێب دەتوانێت ڕووکار و هاوردەکردنی دەق پیشان بدات؛ هاوردەکردنی APKG پێویستی بە سێرڤەری ناوخۆیی هەیە.
