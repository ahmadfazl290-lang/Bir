# بیر — Bîr

پلاتفۆرمێکی بەتاڵی فلاشکارد، بۆ ئەوەی کارتەکانی خۆت هاوردە بکەیت یان بە دەست دروستیان بکەیت. هیچ کارت یان وێنەی خوێندنی پێشوەختەی تێدا نییە. ڕووکاری کوردیی سۆرانی، ئینگلیزی و عەرەبی هەیە.

## دەستپێکردن

1. فۆڵدەری پڕۆژەکە بکەرەوە و دوو کرتە لە `index.html` بکە.
2. لە پەڕەی سەرەکی **هاوردەکردنی فایل** هەڵبژێرە و فایلێکی TXT، TSV یان CSV دیاری بکە. پێش هاوردەکردن، نموونەی کارت و ستوونی پرسیار و وەڵام بپشکنە.
3. یان **دەکێک دروست بکە** هەڵبژێرە، ناوی بنێ و کارتەکانت بە دەست زیاد بکە.

خوێندن، پیشاندانی وەڵام، هەڵسەنگاندنی کارت، گەڕان، دەستکاری، پێشکەوتن و گەڕاندنەوەی دەکە سڕاوەکان لە وێبگەڕدا کار دەکەن. گۆڕینی زمانی ڕووکار دەقی کارتەکان وەرناگێڕێت.

## هاوردەکردنی Anki / APKG

بۆ APKG، لە ناو فۆڵدەری پڕۆژەکە سێرڤەری ناوخۆیی پێ بکە:

```sh
python server.py --port 64008
```

پاشان `http://127.0.0.1:64008/` بکەرەوە و سێرڤەرەکە کارا بهێڵەوە. Python 3.10 یان نوێتر پێویستە. هاوردەکردنی APKG لە ویندۆز پێویستی بە PowerShell 7 (`pwsh`) و ژینگەی Python 3.13ی Ankiی دامەزراو هەیە؛ یاریدەدەرەکە لەگەڵ Anki 26.9.3 تاقی کراوەتەوە. ڕێڕەوی بنەڕەتی Anki بریتییە لە `%LOCALAPPDATA%\Programs\Anki`، کە دەبێت `python313.dll`ی تێدا بێت. Anki لەگەڵ پڕۆژەکەدا نییە.

APKG دەق و وێنە پشتگیریکراوەکان هاوردە دەکات. مێژووی خوێندنی Anki، دەنگ، JavaScript و شێوازە تایبەتەکانی کارت ناگوازرێنەوە. TXT، TSV و CSV بۆ هاوردەکردنی دەقن. هاوردەکردن لە هەمان کۆمپیوتەر ئەنجام دەدرێت.

## پاشەکەوتکردن و کۆپیی پارێزراو

کارت، ڕێکخستن و پێشکەوتن لە وێبگەڕەکەت پاشەکەوت دەکرێن؛ ئەکاونت یان هاوکاتکردن لەگەڵ هەور نییە. ئەم وەشانە پاشەکەوتکردنی جیاوازی هەیە، بۆیە داتای وەشانی پێشووتر خۆکارانە ناگەڕێنێتەوە. هەمان وێبگەڕ و هەمان ناونیشان بەکاربهێنە بۆ دەستگەیشتن بە داتاکانت.

لە **ڕێکخستنەکان** کۆپیی JSON دابەزێنە. JSON کارتەکان و پێشکەوتن دەگرێتەوە، بەڵام خودی وێنەکان لەناویدا نین. فۆڵدەری تەواوی پڕۆژەکە، بە `media/` و وێنە هاوردەکراوەکانەوە، لەگەڵ کۆپییەکە بپارێزە. `media/.gitkeep` فۆڵدەری بەتاڵی وێنەکان لە پڕۆژەدا دەهێڵێتەوە.

## گەشەپێدان

فایلەکانی `app.js`، `core.js` و `styles.css` ڕووکار و ڕەفتاری ئەپەکە پێکدەهێنن. `deck-data.js` تەنها لیستی بەتاڵی دەک و کارتەکانی دەستپێک هەڵدەگرێت. هاوردەکردن لە `text-import.js`، `import-cards.js` و `import-ui.js`دایە.

بە Node.js 24 تاقیکردنەوەکان جێبەجێ بکە:

```sh
npm test
```

پێویست بە `npm install` نییە. ئەمە پلاتفۆرمێکی وێبە؛ APK یان IPAی مۆبایلی تێدا نییە. بۆ ناردنی کۆدی پڕۆژەکە بۆ GitHub، [ڕێنمایی سۆرانی](docs/UPLOAD_TO_GITHUB_SORANI.md) ببینە.

---

**English:** Bîr is an empty flashcard web platform with Sorani Kurdish, English and Arabic interfaces. Open `index.html` for manual cards and TXT/TSV/CSV import. For APKG import, run the local Python server and use the installed Windows Anki runtime and PowerShell 7 described above. Study data stays in this browser under a separate storage key; there is no account or cloud sync. Export a JSON backup and preserve the app folder, including imported `media/`, because JSON does not embed images.
